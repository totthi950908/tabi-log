# たびろぐ（tabi-log）

旅の記録と旅費を、**1回の旅行ごとに**まとめて残すアプリ。友人・家族とは招待リンクで共有できる。

- 訪れた場所の記録（国・都道府県・カテゴリ・評価・メモ）
- 旅費の記録と集計（外貨は旅行ごとのレートで円換算）
- 行った都道府県マップ / 訪れた国の世界地図
- 航空券・ホテル予約サイトへの送客リンク

## 技術スタック

React 18 + TypeScript + Vite + Tailwind CSS + Supabase（推し活アプリと同じプロジェクトの `travel` スキーマに相乗り）。

## セットアップ

```bash
# 1. 依存をインストール
npm install

# 2. 環境変数を設定
cp .env.local.example .env.local
#   → .env.local を開いて Supabase の URL と anon キーを記入

# 3. 開発サーバー起動
npm run dev
```

ブラウザで表示された `localhost` のURLを開く。トップに「Supabase 接続 OK」と出れば環境構築は成功。

## スクリプト

| コマンド | 内容 |

## 注意

- `.env.local` と `service_role` キーは絶対に Git に含めない（`.gitignore` 済み）。
- Supabase は推し活アプリと同じプロジェクトを共有する。データは `travel` スキーマ + RLS で分離される。
